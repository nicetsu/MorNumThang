## 1. ภาพใหญ่ของตลาด

ไทยเป็น aged society แล้ว และโครงสร้างการดูแลยังพึ่งครอบครัวที่ไม่ได้รับการฝึก — ช่องว่างที่แอปนี้ยืนอยู่พอดี

## 2. กลุ่มลูกค้า — ใครจ่าย จ่ายทำไม

ป้ายความยาก: 🟢 เจาะง่าย · 🟡 ปานกลาง · 🔴 ยาก/ช้า · ⭐ โอกาสเด่น

### ก. ผู้บริโภคโดยตรง (B2C)

#### ก.1 ลูก Sandwich Generation ในเมือง — 🟡

- **ตัวเลข:** 64.5% ของผู้สูงอายุ (~9 ล้านคน) อาศัยอยู่กับบุคคลอื่น = ครัวเรือนที่มีคนในบ้านทำหน้าที่ผู้ดูแล ([NSO 2567](https://www.nso.go.th/nsoweb/storage/survey_detail/2025/20241003145311_94190.pdf))
- **Pain:** แบกงาน + ลูก + พ่อแม่พร้อมกัน · 1 ใน 4 ของผู้ดูแลอาชีพสะดุดเพราะภาระดูแล ([NESDC](https://www.nesdc.go.th/wordpress/wp-content/uploads/2025/06/2567_article_q1_003.pdf))
- **เราตอบ:** เตือนยา/นัดผ่าน LINE · แชร์ภาระกับญาติผ่าน invite code · สรุปให้หมอแทนการจำ
- **โมเดล:** Freemium 99–199 บ./เดือน (ครอบครัวหารกัน) — willingness-to-pay ต่ำ ใช้เป็นรายได้เสริม · จับได้ 1% ของ 9 ล้าน = 90,000 ครัวเรือน

#### ก.2 ลูกที่อยู่คนละจังหวัดกับพ่อแม่ (remote caregiving) — ⭐ 🟢

- **ตัวเลข:** ผู้สูงอายุอยู่คนเดียว 12.9% (~1.8 ล้านคน) + อยู่ลำพังกับคู่สมรส 22.6% (~3.2 ล้านคน) = **~5 ล้านคนไม่มีลูกอยู่บ้านเดียวกัน** และสัดส่วนอยู่คนเดียวโตเกือบ 4 เท่าใน 30 ปี (3.6% → 12.9%) ([NSO 2567](https://www.nso.go.th/nsoweb/storage/survey_detail/2025/20241003145311_94190.pdf), [มนุษย์ต่างวัย](https://www.manoottangwai.com/elderly-living-alone/))
- **Pain:** พ่อแม่อยู่ต่างจังหวัด ลูกทำงาน กทม. รู้ข่าวผ่านโทรศัพท์วันละครั้ง · ครอบครัวชุมชนดั้งเดิมมีภาระดูแลสูงกว่าหมู่บ้านจัดสรร 2.7 เท่า ([PMC](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC11202914/))
- **เราตอบ:** ญาติ/อสม. ที่อยู่บ้านจด → ลูกใน กทม. เห็น doctor-score เรียลไทม์ + LINE แจ้งเตือน — **multi-caregiver ของเราออกแบบมาเพื่อสิ่งนี้พอดี**
- **โมเดล:** กลุ่มที่ยอมจ่ายสูงกว่า ก.1 เพราะซื้อ "ความสบายใจจากระยะไกล"

#### ก.3 ผู้สูงอายุดูแลตัวเอง (active aging 60–75) — 🔴

- **เรามีแล้ว:** ฟีเจอร์ "โปรไฟล์ตัวเอง + เชิญคนมาดูแลเรา" อยู่ในโค้ดแล้ว
- **โมเดล:** ฟรี — ใช้เป็นทางเข้า: คนแก่ชวนลูกเข้าแอป = acquisition กลับด้าน

### ข. สถานพยาบาล (B2B)

#### ข.1 รพ.เอกชน / คลินิกเวชศาสตร์ผู้สูงอายุ — 🟢

- **ตัวเลข:** รพ.เอกชนทั่วประเทศ **~370 แห่ง — อยู่ใน กทม. 116 แห่ง (31%)** + คลินิกทุกประเภททั่วประเทศกว่า 21,400 แห่ง ([Krungsri Research](https://www.krungsri.com/th/research/industry/industry-outlook/services/private-hospitals/io/io-private-hospitals))
- **Pain:** หมอเจอคนไข้ 10 นาที ไม่รู้ว่า 90 วันที่บ้านเกิดอะไรขึ้น · รพ.เอกชนแข่งด้วย "ประสบการณ์ผู้ป่วย"
- **เราตอบ:** "สรุปให้หมอ" + ประวัติ 15 วัน + NEWS2 = home monitoring ที่หมอไม่เคยได้
- **โมเดล:** White-label / subscription ต่อสาขา (~20,000–50,000 บ./เดือน) ให้ รพ. แจกญาติคนไข้ · sales cycle 3–6 เดือนแต่จ่ายจริง

#### ข.2 รพ.รัฐ / รพ.สต. / คลินิกหมอครอบครัว — 🔴 ช้า

- **ตัวเลข:** รพ.สต. เกือบ 10,000 แห่งทั่วประเทศ — เครือข่ายปฐมภูมิที่ใกล้ผู้สูงอายุที่สุด
- **บริบท:** สธ. ดัน "สาธารณสุขดิจิทัล" (ใบส่งตัวออนไลน์, หมอพร้อม) — ทิศทางนโยบายเอื้อ
- **ทางเข้า:** ขายตรงยาก (จัดซื้อราชการ) → เข้าทางโครงการนำร่อง/ทุนวิจัย (สวรส., สสส.) หรือผ่าน อปท.

### ค. รัฐ / ท้องถิ่น

#### ค.1 กองทุน LTC + อปท. (Care Manager / Caregiver) — ⭐ ตลาดซ่อนที่ใหญ่มาก 🟡

- **ตัวเลข:** ผู้มีภาวะพึ่งพิงเป้าหมายการดูแล **106,807 คน** · Care Manager ทั้งระบบ **13,615 คน** · Caregiver **~86,800 คน** (อัตรา CM:CG = 1:6.4) + โครงการจ้าง CG เพิ่ม **18,587 อัตรา เรต 5,000 บ./เดือน** ([TheCoverage](https://www.thecoverage.info/news/content/9268), [LTC Fact Sheet](https://hrpo.info/wp-content/uploads/2024/10/LTC_fact-sheet-02-CM.pdf))
- **โครงสร้าง:** CM 1 คนดูแลผู้สูงอายุติดบ้านติดเตียง ~65 ราย มี CG (อสม. อบรม 70 ชม.) ช่วย · งบ ~205,000 บ./ปี/ตำบล
- **Pain:** CM/CG จดกระดาษ ทำ care plan ส่งเบิก สปสช. ด้วยมือ — **เครื่องมือดิจิทัลสำหรับ CG แทบไม่มี**
- **เราตอบ:** แอปเราคือเครื่องมือ CG ได้เลย (จดง่าย พูดได้ ปุ่มใหญ่) + doctor-score ช่วย CM จัดลำดับการเยี่ยม
- **โมเดล:** License ต่อ อปท. 20,000–50,000 บ./ปี/ตำบล (อปท. จัดซื้อเองได้ วงเงินเล็ก) · ceiling = 7,850 แห่ง

#### ค.2 ร้านยา / หน่วยบริการนวัตกรรม สปสช. — 🟡

- **ตัวเลข:** งบหน่วยนวัตกรรมปี 2569 **~3,000 ลบ.** (จากจุดตั้งต้น 1,500 ลบ. ปี 2568) ภายใต้งบบัตรทองรวม 272,583 ลบ. ([Hfocus](https://www.hfocus.org/content/2025/01/32750), [Hfocus ก.ค. 69](https://www.hfocus.org/content/2026/07/38840))
- **บริบท:** 7 ประเภทหน่วย (ร้านยา คลินิกพยาบาล คลินิกเวชกรรม ทันตกรรม แพทย์แผนไทย กายภาพ เทคนิคการแพทย์) · แอปเราชี้ผู้ใช้บัตรทองไปหาเขาอยู่แล้ว (`lib/rights.ts`, `lib/free-meds.ts`)
- **โมเดล:** Referral fee ต่อเคสที่ส่งไป หรือขายระบบจัดการเคสให้หน่วยบริการ

### ง. สถานดูแล (B2B)

#### ง.1 Nursing home — 🟢

- **ตัวเลข:** ~600 แห่งขึ้นทะเบียนถูกกฎหมาย (ประมาณการเตียงรวมหลักหมื่นเตียง — ยังไม่มีสถิติทางการ) · ตลาดโตจาก 2,574 ลบ. → คาด 19,200 ลบ. ใน 10 ปี ([trade.gov](https://trade.gov/market-intelligence/thailand-eldercare-facilities))
- **Pain:** ญาติไม่เห็นว่าเกิดอะไรกับพ่อแม่ในศูนย์ → ไม่ไว้ใจ · ศูนย์รายงานญาติด้วย LINE ส่งรูปกระจัดกระจาย
- **เราตอบ:** ศูนย์จดในแอป → ญาติเห็น timeline + doctor-score = เครื่องมือสร้างความไว้ใจที่ศูนย์เอาไปขายต่อได้
- **โมเดล:** Subscription ต่อเตียง 50–100 บ./เตียง/เดือน — ศูนย์คิดต่อกับญาติได้ 3–5 เท่า · เจ้าของตัดสินใจคนเดียว ปิดเร็ว

#### ง.2 Home care agency — 🟡

ให้ผู้ดูแลมืออาชีพของ agency ใช้แอปเราจดแล้วรายงานญาติ → licensing หรือเป็น partner ไม่ใช่คู่แข่ง

#### ง.3 Senior living / retirement community — 🔴 เก็บไว้ทีหลัง

อสังหาสูงวัยกำลังบูม (Jin Wellbeing, เชียงใหม่, หัวหิน) แต่ลูกค้าหลักเป็น expat — ติด UI ไทยล้วน

### จ. องค์กรจ่ายแทน

#### จ.1 ประกันชีวิต / ประกันสุขภาพ — 🟡

- **สัญญาณ:** เมืองไทยประกันชีวิต (ผ่าน Fuchsia VC) ลงทุนใน Health at Home แล้ว = ตลาดพิสูจน์ว่าประกันสนใจ
- **โมเดล:** Wellness benefit แถมกรมธรรม์ผู้สูงวัย · ข้อมูล adherence (แบบ consent) ช่วยประกันลด claim

#### จ.2 นายจ้าง (employee benefit) — 🟡 ตลาดใหม่

เทรนด์ Family-Friendly Workplace กำลังมา — สวัสดิการพนักงาน sandwich gen ยังไม่มีใครทำในไทย

## 3. คู่แข่งในประเทศ

ส่วนใหญ่แข่งกันเรื่อง "หาคน" หรือ "พบหมอ" — ยังไม่มีใครยืนตรงจุด "ข้อมูลการดูแลรายวันที่บ้าน"

### Buddy HomeCare — เชียงใหม่ · social enterprise

จับคู่เยาวชนขาดโอกาส (อบรมแล้ว) ไปดูแลผู้สูงอายุยากไร้ มีแอป monitor สุขภาพ — โมเดลสังคมที่ได้รางวัลระดับสากล

> ⚠️ ใกล้เราที่สุดเชิงฟีเจอร์ monitoring — แต่เป้าหมายเป็น social impact ไม่ใช่ scale เชิงพาณิชย์ → **เป็น partner นำร่องภาคเหนือได้เลย**

### Health at Home — กทม. · startup มี VC หนุน

ส่งผู้ดูแลมืออาชีพถึงบ้าน + remote monitoring มีทีมพยาบาลกำกับ ผู้ลงทุนรวม 500 TukTuks, Fuchsia VC (เมืองไทยประกันชีวิต), กองทุน SET+ออมสิน

> ⚠️ ทับกันบางส่วนตรง monitoring — แต่ลูกค้าเขาคือคนจ้างผู้ดูแล (หลักหมื่น/เดือน) เราคือครอบครัวที่ดูแลกันเอง ซึ่งใหญ่กว่ามาก → **ตลาดคนละชั้น และเป็นผู้ซื้อ license ที่เป็นไปได้**

### Saijai / VNurseCare — กทม. · marketplace

Directory/จองคนดูแล แม่บ้าน พาไปหาหมอ — ธุรกิจอยู่ที่ค่าคอมมิชชันการจับคู่

> ✅ ไม่ชนกัน — เขาหา "คน" เราจัดการ "ข้อมูล" ต่อยอดเป็น integration ได้ (ผู้ดูแลที่จ้างผ่านเขา มาจดในแอปเรา)

### MorDee / Chiiwii / ZeekDoc — telemedicine

พบหมอออนไลน์ ปรึกษา จ่ายยา — แข่งกันที่จำนวนหมอและราคา

> ✅ คนละเรื่อง — เขาขาย "ครั้งที่พบหมอ" เราขาย "ข้อมูลระหว่างครั้งที่พบหมอ" — เผลอ ๆ เป็นผู้ซื้อข้อมูลสรุปของเราด้วยซ้ำ

### หมอพร้อม + Health Link — ภาครัฐ

ระเบียนสุขภาพแห่งชาติ นัดหมาย ใบส่งตัวอิเล็กทรอนิกส์ — โครงสร้างพื้นฐานของ สธ.

> ⚠️ ไม่ใช่คู่แข่งวันนี้ (ไม่มีเครื่องมือผู้ดูแล) แต่คือ **platform risk ระยะยาว** → กลยุทธ์ที่ถูกคือหาทาง integrate ไม่ใช่แข่ง

### SaiJai.co / อาวุโสไทย — directory บ้านพักคนชรา

รวมรายชื่อ nursing home ทั่วประเทศให้ครอบครัวค้นหา

> ✅ ไม่ชน — และเป็น **แหล่งรายชื่อลูกค้า (lead list)** สำหรับแผนขาย nursing home ของเราโดยตรง

## 4. ตัวอย่างต่างประเทศ — ใครรอด ใครร่วง เพราะอะไร

บทเรียนตรงที่สุด: **แอป caregiver ที่ขายผู้บริโภคตรง ๆ ตายเกือบหมด — ตัวที่รอดขายให้ "องค์กรที่จ่ายแทน"**

| เจ้า | ประเทศ/สถานะ | ทำอะไร | บทเรียนสำหรับเรา |
|---|---|---|---|
| **CareZone** | 🇺🇸 B2C — **ปิดตัวแล้ว** | แอปจัดการยา+สุขภาพให้ครอบครัว มีผู้ใช้หลักล้าน ขายให้ Walmart แล้วถูกปิดปี 2023 | ผู้ใช้เยอะ ≠ ธุรกิจรอด — B2C caregiver ล้วน ๆ เก็บเงินยาก **ต้องมีขา B2B ตั้งแต่ต้น** |
| **Papa** | 🇺🇸 ระดมทุน ~$241M | ส่ง "Papa Pals" เป็นเพื่อน/ผู้ช่วยผู้สูงอายุ — คนจ่ายคือ Medicare Advantage และนายจ้าง | โมเดล **"payer จ่ายแทน"** (ประกัน/นายจ้าง) คือทางที่ scale ได้จริง = หมวด จ. ของเรา |
| **Honor** | 🇺🇸 ระดมทุน ~$635M | ไม่เปิด agency เอง แต่เป็น "ระบบปฏิบัติการ" ให้ home care agency ท้องถิ่นใช้ | **ติดอาวุธให้ผู้เล่นเดิม ชนะการไปแข่งกับเขา** = ตรงกับแผน ง.2 |
| **Birdie** | 🇬🇧 SaaS | แพลตฟอร์มบริหารงานดูแลสำหรับ care agency — จัดตาราง บันทึกการเยี่ยม วิเคราะห์ความเสี่ยง ครอบครัวเห็นรายงาน ใช้ทั่ว UK/ยุโรป | โครงสร้าง**เหมือนตลาด LTC ไทยที่สุด** (รัฐจ่าย → agency ทำงาน → ครอบครัวดูรายงาน) — คือภาพอนาคตของแผน ค.1 |
| **บริการเฝ้าดูแล** (เช่น Japan Post みまもり) | 🇯🇵 | ไปรษณีย์ส่งเจ้าหน้าที่เยี่ยมผู้สูงอายุรายเดือน รายงานลูกที่อยู่ไกลผ่านแอป คิดรายเดือน | ยืนยันว่า segment ก.2 **จ่ายจริง** — และคนจดไม่จำเป็นต้องเป็นญาติ อาจเป็น อสม./ไปรษณีย์/ร้านค้าชุมชน |

| | |
|---|---|
| **เป้า** | 1 ตำบลนำร่องในลำปาง/ลำพูน → 20–50 อปท. ปีที่ 2 ผ่านชมรม CM / สันนิบาตเทศบาล |
| **90 วันแรก** | หา partner วิชาการ (คณะพยาบาล มช. / สวรส.) → อบรม CG ใช้แอป 1 ตำบล → เก็บผลเป็น case study |
| **รายได้** | ปีแรก = ทุนวิจัย/CSR (สสส.) → ปี 2: 30 อปท. × 30,000 บ./ปี ≈ **0.9 ลบ.** · ceiling 7,850 อปท. |
| **ต้องสร้าง** | โหมด CG ดูหลายบ้าน · export รายงานตามฟอร์ม สปสช. · ทนสัญญาณเน็ตอ่อน |
| **ความเสี่ยง** | วงจรราชการช้า · เปลี่ยนนายก อปท. นโยบายเปลี่ยน → **ผูกกับ CM (ข้าราชการประจำ) ไม่ใช่ฝ่ายการเมือง** |

### แผน C — LINE Viral "ลูกกตัญญู" (ฐานผู้ใช้ก่อน)

| | |
|---|---|
| **เป้า** | 10,000 ครอบครัวใน 12 เดือน เน้น ก.2 (ลูกไกลบ้าน) |
| **90 วันแรก** | คอนเทนต์ "เช็คสุขภาพแม่จากกรุงเทพ" TikTok/Facebook → invite code ดึงญาติ 2–3 คน/ครอบครัว |
| **รายได้** | ช้าสุด — freemium + ต่อยอดขายประกัน/นายจ้าง เมื่อฐานพิสูจน์ engagement |
| **ต้องสร้าง** | Onboarding จบใน 3 นาที · share doctor-score ลง LINE กลุ่มครอบครัว (viral loop) |
| **ความเสี่ยง** | เผาเงิน marketing โดยไม่มีรายได้ — ควรเป็นเลนคู่ขนาน ไม่ใช่แผนเดี่ยว (**บทเรียน CareZone**) |

### คำแนะนำ

**A เป็นแกน + C เป็นเงา แล้วเปิด B เมื่อมีคน/ทุนพอ**

- **A** พิสูจน์ว่ามีคนยอมจ่าย (สำคัญสุดระยะนี้)
- **C** วิ่งคู่ไปแทบไม่มีต้นทุนเพราะ LINE infra พร้อมแล้ว
- **B** คือ ceiling ใหญ่สุดระยะยาว แต่ต้องอดทนกับราชการ

> ⚠️ **ก่อนรับเงินลูกค้ารายแรกไม่ว่าแผนไหน:** PDPA + session จริง + backup ข้อมูล — สามด่านบังคับของ health data
> (ตอนนี้ auth ยังเป็น cookie 2 ตัวแบบ ponytail — ดู `lib/patient.ts`)
