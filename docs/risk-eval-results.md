## สรุป: method ถูก, จุดอ่อนคือโมเดล — และแก้ได้ด้วย prompt

| เวอร์ชัน | สิ่งที่แก้ | ผล (ถูก/7) |
|---|---|---|

| v2 | + กฎ "ห้ามแต่งอาการ" | 4/7 — **ไม่ช่วย** เคส 2 (เลือด) แย่ลง (ทิ้งเนื้อจริง) |
| **v3** | **เปลี่ยนตัวอย่างใน prompt เป็น schema เปล่า** | **6/7 ✓** (อีก 1 เป็น caution-high บนสัญญาณจริง ไม่ใช่บั๊ก) |

**ต้นเหตุที่เจอ:** ตัวอย่างใน prompt เขียน `"text":"กินน้อยลง"` → โมเดล 8B **ลอกตัวอย่างมาเป็นคำตอบ**
(few-shot echo) ทำให้แต่งอาการ "กินน้อยลง" ที่ไม่มีในเรื่อง → escalate ผิด · แก้โดยทำตัวอย่างเป็น
schema placeholder (`"text":"<สรุปสิ่งที่เล่าจริง>"`) → หายทันที

**บทเรียนสำคัญ:** โมเดลเล็กลอก few-shot example ตรงๆ — ตัวอย่างต้องเป็น placeholder ไม่ใช่ค่าจริง.
และ **keyword safety-net พิสูจน์คุณค่า**: หลายเคส LLM สกัด sign พลาด แต่ keyword net จับจากข้อความได้เอง.

## v4 — ขยายเป็น 16 เคส → เจอ + แก้ gap "base-symptom key แคบไป"
เพิ่มอาการ (ไข้/หายใจ/หกล้ม/UTI/ท้องเสีย/DVT/stroke + เรื้อรัง/ธรรมดา) แล้วเจอ **under-triage 3 เคส** —
ทั้งหมดมาจากสาเหตุเดียว: ญาติพูดคนละคำกับชื่ออาการทางการ → base symptom ไม่ match → danger sign ไม่ถูกเช็ค:
- "**ลื่นล้ม** หัวฟาดพื้น" ≠ key "หกล้ม" → หัวกระแทกไม่ยิง (ควรสังเกต แทนปรึกษาหมอ)
- "**ท้องเสีย**" ≠ key "ถ่ายเหลว" → ขาดน้ำไม่ยิง
- "**ขาซ้ายบวม**" ≠ key "ขาบวม" → **DVT พลาดเป็นปกติ!** (อันตรายสุด)

**แก้:** ทำ base key เป็น **array ของ alias** (`keys: ["ล้ม","หกล้ม","ลื่นล้ม"]`, `["ท้องเสีย","ถ่ายเหลว",...]`, `["บวม","ขาบวม"]`)
→ ทั้ง 3 เคสจับได้ด้วย keyword net เอง (มี regression test คุมใน `risk.test.mts`)

## ข้อสังเกต
- **การขึ้นแดง (danger sign / Class A / delirium / stroke) แม่นทุกเคส** — จุด safety สำคัญสุด
- **negation / เรื่องดี / หายแล้ว / เรื้อรังคงที่ → ปกติ ถูกทุกเคส** — ไม่ over-triage (แม้ปวดเข่าเรื้อรังทุกวัน)
- **union พิสูจน์คุณค่าจริง** เคส "หอบเหนื่อย หายใจไม่ทัน นอนราบไม่ได้" → keyword net **พลาด** (W5 negation false-negative:
  "ไม่" ใน "หายใจไม่ทัน" ไปบัง danger "นอนราบไม่ได้") แต่ **LLM สกัด [นอนราบไม่ได้] มาช่วย** → ควรปรึกษาหมอ ✓
  → ยืนยันว่าต้อง union (keyword ∪ LLM), ไม่พึ่งอย่างใดอย่างหนึ่ง · W5 negation window ยังหยาบ = limitation ที่รู้ตัว
- เคสเดียวที่สูงกว่าคาด (2+ soft sign ผู้สูงอายุ → ปรึกษาหมอ) = **caution-bias บนสัญญาณจริง** (ไม่ใช่ hallucination) — threshold รอแพทย์ review
- ทดสอบด้วย 8B typhoon; โมเดลใหญ่กว่าจะสกัด sign ครบกว่า (ลด reliance บน keyword net)
